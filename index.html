Data science became the natural extension of that passion: mathematical rigor applied to real problems. My long-term goal is to be an ambassador for science and technology, starting as a data scientist in banking.

Work

NeuroEgo

An assistive brain-computer interface idea that turns brain signals into text, speech and commands. The idea reached the Mastercard final; the device itself is not built. My bootcamp capstone builds a software prototype: a Random Forest on a public EEG dataset (98.8% test accuracy) with a Streamlit demo on recorded signals, no hardware.

Python · scikit-learn · Streamlit

Bahraini Food Detection

A YOLO model fine-tuned on our own dataset of ten Bahraini dishes, with error analysis and a second data round to improve it.

YOLO · Roboflow · Streamlit

Bahraini Currency Recognition

Classifying Bahraini dinar notes with deep learning and transfer learning, deployed as a Streamlit app.

PyTorch · Transfer learning

Doodle Search & Bahrain Reviews

A doodle search engine on Keras embeddings, and sentiment plus zero-shot analysis of Bahrain restaurant reviews with Hugging Face.

Keras · Hugging Face

Banking Systems

A Java, SQL and JDBC transaction system, and SmartBank, a Python platform for account KPIs. Also researched combining Newton's method with binary search for precise valuation models.

Java · Python · SQL
